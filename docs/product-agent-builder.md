# Product Agent — Builder

Vibe-codes tools, websites, and apps based on your briefs.

## Capabilities

- **Frontend (HTML/React)** — single-page UIs, component-driven layouts, responsive design.
- **Landing pages** — marketing pages with hero, features, CTAs, and SEO basics.
- **SaaS micro-tools** — small, focused utilities (calculators, generators, converters, dashboards).
- **Browser extensions** — Chrome/Firefox MV3 extensions with popup, content scripts, and background workers.

## Inputs

A short brief describing:
- Goal / problem to solve
- Target user
- Key features (must-have vs nice-to-have)
- Visual style or brand references (optional)
- Distribution target (web, extension store, etc.)

## Output

A working scaffold with:
- Source code
- Build/run instructions
- Minimal styling and accessible defaults
